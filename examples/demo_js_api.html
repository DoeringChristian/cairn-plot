cairn-plot — JS / HTML API

Every plot below is authored in JavaScript via cairnPlot.* — the same builder surface as Python's cairn_plot. Data rides by reference (the HDR image is a Float32Array, no base64).

Line — cairnPlot.line({loss, val}, x)

Scatter with colormap — cairnPlot.scatter(xs, ys, {color, colormap})

HDR image from a Float32Array — cairnPlot.image(f32, {shape, tonemap})

Compare (abs diff) — cairnPlot.compare(a, b, {mode: "abs"})

Grid — cairnPlot.grid([[line, bar]])
